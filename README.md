# SoundBall Fútbol 5

Fútbol 5 en tiempo real con sonido 3D, narrador y modo mánager. Accesible con lector de pantalla.
Partidos en tiempo real con sonido 3D, narrador y comentarista, y modo mánager con liga, copa, Copa Continental y selecciones.

**Versión de prueba** (acceso para testers).

**Descargar:** en [Releases](https://github.com/brianheli/no-look-goal-juego/releases/latest), el archivo `No-Look-Goal.zip`.
Descomprímelo en una carpeta y abre `SoundBall Futbol 5.exe`. Para Windows de 64 bits. Mejor con auriculares.
Dentro viene la guía completa: `Guia de SoundBall.html` (también se abre desde el menú del juego).
El juego se actualiza solo desde el menú: **Buscar actualización**. Tus carreras y ajustes no se pierden.

## English

Real-time 5-a-side football with 3D sound, commentators and a manager mode. Works with screen readers.
The whole game is in English and Spanish, with English commentators (American and British): choose the language in
Settings > Idioma / Language.

**Download:** in [Releases](https://github.com/brianheli/no-look-goal-juego/releases/latest), the file `No-Look-Goal.zip`.
Unzip it into a folder and open `SoundBall Futbol 5.exe`. For 64-bit Windows. Best with headphones.
The full guide comes inside: `SoundBall Guide.html` (it also opens from the game menu).
The game updates itself from the menu: **Check for updates**. Your careers and settings are kept.
